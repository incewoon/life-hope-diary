# 일간 플랜 글자 크기 변경 시 첫 단어 동반 변경 수정

## 확인된 원인

텍스트 도구에서 크기를 선택하면 커서 위치에 새 크기의 `span`을 만드는 동시에, 편집 영역 전체의 기본 `font-size`도 현재 선택값으로 변경되고 있습니다. 기존 문장 중 별도 `span`으로 감싸지지 않은 첫 단어가 이 기본 크기를 상속하기 때문에, 커서 이후 입력분과 함께 첫 단어까지 바뀝니다. 색상은 편집 영역 전체 값과 연결되어 있지 않아 정상입니다.

## 수정 내용

1. 편집 영역 전체의 기본 글자 크기를 고정된 기본값으로 유지합니다.
2. 툴바에서 바꾼 글자 크기는 현재 커서에 삽입되는 서식 구간 또는 사용자가 선택한 구간에만 적용합니다.
3. 기존에 저장된 HTML과 색상 적용 로직은 변경하지 않습니다.
4. 새 문서의 기본 입력 크기와 저장된 서식 없는 텍스트는 기존 기본 크기로 동일하게 표시되도록 유지합니다.

## 기술 메모

- `src/components/HandwritingCanvas.tsx`: `CanvasTextLayer`의 전체 `baseSize`가 툴바 `textSize` 상태를 따라 바뀌지 않도록 분리합니다.
- `src/components/CanvasTextLayer.tsx`: 필요하면 기본 크기 책임을 명확히 하여, 개별 인라인 `font-size`만 혼합 크기를 표현하도록 정리합니다.
- 색상 처리와 선택 영역 서식 로직은 그대로 둡니다.

## 검증

- 첫 단어와 이후 문장을 기본 크기로 입력한 뒤, 문장 중간에서 크기를 변경하고 계속 입력했을 때 첫 단어가 변하지 않는지 확인합니다.
- 연속으로 여러 번 크기를 변경해 각 구간의 크기가 독립적으로 유지되는지 확인합니다.
- 드래그 선택한 구간만 크기가 바뀌는지 확인합니다.
- 색상 변경이 기존처럼 정상 동작하는지 회귀 확인합니다.
- 새로고침 후 모든 크기 구간이 그대로 복원되는지 확인합니다.
