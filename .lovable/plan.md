# 필기 영역 자동 크기 + 늘리기 버튼

## 1. 화면 크기·방향에 맞춘 자동 높이

- 일간 플랜의 자유 필기 영역이 태블릿 화면 높이에 맞춰 자동으로 잡히도록 합니다.
- 기준 높이 = 브라우저 창 높이에서 필기 영역 위쪽 요소(헤더, 날짜 이동, 일정 영역, 툴바)가 차지한 높이를 뺀 값. 즉 필기판이 화면 아래까지 딱 채워집니다.
- 가로/세로 모드 전환, 창 크기 변경, 일정 추가로 위쪽 높이가 달라질 때 자동으로 다시 계산합니다.
- 너무 작아지지 않도록 최소 높이(약 320px)는 유지합니다.

## 2. 하단 "늘리기" 버튼

- 필기 영역 아래에 "늘리기" 버튼을 둡니다. 누를 때마다 기준 높이의 1배만큼 세로 길이가 추가됩니다(1배 → 2배 → 3배 …, 반복 제한 없음).
- 함께 "줄이기" 버튼도 두어 한 단계씩 되돌릴 수 있게 합니다(1배 미만으로는 줄지 않음). 현재 배수는 버튼 옆에 "1배 / 2배"처럼 표시합니다.
- 늘린 배수는 해당 날짜 페이지에 저장되어, 다시 그 날짜를 열면 늘려둔 상태 그대로 보입니다.
- 이미 그린 필기는 가로 폭 기준으로 저장되므로, 높이를 늘려도 위치와 크기가 그대로 유지되고 아래쪽 빈 공간만 늘어납니다.

## 기술 메모

- `HandwritingCanvas`에 옵션 추가: `autoHeight?: boolean`, `resizable?: boolean`, `heightUnits`/`onHeightUnitsChange` (제어형) — 기존 `minHeight` 사용처(회의록·노트·연락처·월간)는 변경 없이 그대로 동작.
- 기준 높이 계산: 컨테이너의 `getBoundingClientRect().top`을 읽어 `window.innerHeight - top - 여유(16px)`, `Math.max(320, …)`로 하한 적용. `window` resize·`orientationchange` 및 상위 레이아웃 변경 감지를 위해 `ResizeObserver`(document.body)로 재계산.
- 실제 컨테이너 높이 = `기준높이 * units`. 기존 `ResizeObserver` 기반 캔버스 리사이즈 로직이 그대로 캔버스 픽셀 크기를 갱신하므로 재그리기는 자동.
- 배수 저장: 일간 페이지의 `usePageText` `textFields.canvasUnits`에 숫자 문자열로 저장(필기 `strokes`와 간섭 없음). 라우트에서 상태를 들고 `HandwritingCanvas`에 내려줍니다.
- 늘리기/줄이기 버튼은 필기 영역 하단에 작은 버튼 줄로 렌더(`ChevronsDown` / `ChevronsUp` 아이콘, 기존 디자인 토큰 사용).
