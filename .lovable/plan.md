# 일간 플랜 UI 개편

## 1. 헤더 / 날짜 이동 재배치

- 페이지 최상단 제목은 "일간 플랜"(현재 제목 글씨 크기 그대로), 부제는 저장 상태만 표시.
- 그 아래 날짜 이동 줄을 배치: `< 이전 날짜` — **2026년 8월 25일 (화)** — `다음 날짜 >`.
- 선택된 날짜는 이전/다음 버튼 사이 중앙에 크고 굵게 표시.

## 2. 일정 입력 팝업 재설계 (삼성 캘린더 스타일)

- 필드 구성: 일정 이름 / 시작(날짜 + 시간) / 종료(날짜 + 시간).
- 기본값: 현재 보고 있는 날짜 + 현재 시각을 30분 단위로 올림한 시각, 종료는 시작 +1시간.
- 날짜는 버튼을 누르면 달력 팝오버, 시간은 30분 단위 목록에서 선택(스크롤 리스트, 현재 값 강조). 기존 원형 다이얼은 제거.
- 저장 / 취소 / (기존 일정) 삭제 유지. 칩에는 `시작시간–종료시간 · 일정명` 표시.
- 저장 형식은 기존 JSON 배열에 `end` 필드를 추가(`{id, at, end, title}`). 기존 데이터는 `end`가 없으면 시작 +1시간으로 간주.

## 3. 도구영역 배치 정리

좌 → 우 순서: **배경** → **필기/타이핑 모드 토글** → (필기 선택 시에만) 지우개·형광펜·펜 설정 → (타이핑 선택 시에만) 글자 크기·글자 색상 → 실행취소/다시실행/전체지우기 → 확대·축소 → 저장 상태.

- 글자 크기 버튼 라벨에 현재 값 표시: `글자 크기(크게)`.

## 4. 형광펜 모드

- 필기 모드 안에 형광펜 토글 추가. 색상은 노란 형광색 고정, 굵기는 펜보다 두껍게, 반투명으로 그려져 글씨가 비쳐 보임.
- 형광펜 획도 일반 획과 같은 방식으로 저장/실행취소/지우개 대상이 됨.

## 5. 확대 / 축소

- 도구영역 최우측에 `−` / `+` 버튼. 필기 캔버스와 텍스트 레이어를 함께 확대·축소(예: 50%~200%, 10% 단위).
- 확대 시 스크롤 영역이 커지며 두 손가락 이동으로 탐색 가능. 배율은 페이지별로 저장되어 다시 열어도 유지.

## 6. 스크롤바 두껍게 (손가락 조작)

- 우측·하단 스크롤바를 손가락으로 잡고 끌 수 있도록 두껍게(약 16px) 하고 대비가 보이는 색으로 표시.
- 현재 스크롤 컨테이너가 모든 터치를 막고 있어 스크롤바 드래그가 안 되므로, 터치 차단은 캔버스에만 적용하도록 조정(두 손가락 이동 기능은 그대로 유지).

## 기술 메모

- `src/routes/daily.$year.$month.$day.tsx`: `PageShell` title을 "일간 플랜"으로 바꾸고, 날짜 표시를 이전/다음 링크 사이로 이동. 확대 배율은 `usePageText`의 `canvasZoom` 필드에 저장.
- `src/components/DaySchedule.tsx`: `ClockPicker`/`Dial` 제거, 시작·종료 행 + 달력 팝오버 + 30분 단위 시간 리스트로 교체. `ScheduleItem`에 `end` 추가 및 하위호환 파싱.
- `src/components/HandwritingCanvas.tsx`
  - 툴바 순서 재구성, 조건부 노출(지우개·형광펜은 필기 모드, 글자 옵션은 텍스트 모드).
  - 형광펜: `usePen`에 `highlighter` 도구 추가, 획 저장 시 `color`를 반투명 노랑(rgba)으로, `width`는 고정 굵기. 렌더는 기존 `strokePath` 채우기 그대로 사용하므로 DB 스키마 변경 없음.
  - 확대: 보드 wrapper에 `transform: scale(z)` + `transform-origin: 0 0`, 스크롤 콘텐츠 크기를 `boardWidth*z`로 맞추고 `toPoint`에서 `z`로 나눠 좌표 보정(저장 좌표는 계속 baseWidth 정규화 유지).
  - 스크롤 컨테이너 `touchAction`을 `auto`로, 캔버스에만 `touch-none` 유지. 두꺼운 스크롤바용 유틸리티를 `src/styles.css`에 추가(`::-webkit-scrollbar` 16px).
- `src/lib/pen-context.tsx`: `PenTool`에 `"highlighter"` 추가, 형광색 상수 정의.
