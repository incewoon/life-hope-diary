# 필기 영역: 고정 기준 크기 + 스크롤 + 아래/오른쪽 늘리기

## 1. 초기 크기는 "가로모드 기준" 고정값

- 필기판 크기를 화면에 맞춰 실시간으로 늘였다 줄였다 하지 않습니다. 대신 기기 화면을 한 번 읽어 **가로모드 기준의 고정 크기**를 초기값으로 정합니다.
  - 기준 폭 = 화면의 긴 쪽 길이(가로모드 폭)에서 좌측 네비게이션과 여백을 뺀 값
  - 기준 높이 = 화면의 짧은 쪽 길이에서 상단 헤더·일정 영역·툴바를 뺀 값
- 이 값은 해당 날짜 페이지에 저장되어, 이후에는 화면을 돌려도 필기판 크기가 변하지 않습니다.
- 세로모드로 전환하면 화면보다 필기판이 넓으므로 **가로 스크롤**이, 아래로 늘렸다면 **세로 스크롤**이 생깁니다. 즉 화면 회전이 필기 내용에 전혀 영향을 주지 않습니다.

## 2. 아래/오른쪽 늘리기

- 필기 영역 아래에 컨트롤 줄을 둡니다.
  - "아래로 늘리기" — 기준 높이의 1배씩 세로 추가 (반복 가능)
  - "오른쪽으로 늘리기" — 기준 폭의 1배씩 가로 추가 (반복 가능)
  - 각각 되돌리는 "줄이기" 버튼(1배 미만으로는 축소 불가). 현재 상태는 "가로 2 × 세로 3" 형태로 표시합니다.
- 늘린 배수는 날짜별로 저장되어 다시 열면 그대로 유지됩니다.
- 늘려도 이미 그린 필기는 위치·크기가 변하지 않고, 빈 공간만 오른쪽/아래로 추가됩니다.
- 모눈 배경은 늘어난 전체 영역에 이어서 그려집니다.

## 3. 스크롤 동작

- 필기판은 스크롤 컨테이너 안에 놓입니다. 화면보다 크면 가로·세로 스크롤이 생깁니다.
- 펜/손가락으로 그리는 동안에는 스크롤이 따라 움직이지 않도록 캔버스는 지금처럼 터치 스크롤을 막고(`touch-none`), 스크롤은 컨테이너 가장자리 스크롤바나 두 손가락 제스처로 합니다.

## 기술 메모

- `HandwritingCanvas`에 옵션 추가: `fixedSize?: { baseWidth: number; baseHeight: number }`, `cols`/`rows`와 `onGridChange` (제어형). 기존 `minHeight` 사용처(월간·회의록·노트·연락처)는 그대로 유지.
- **좌표 정규화 변경(중요)**: 현재 stroke 좌표는 컨테이너 실제 폭으로 나눠 저장하므로 폭이 바뀌면 필기가 통째로 스케일됩니다. 고정 크기 모드에서는 컨테이너 폭 대신 **저장된 기준 폭(baseWidth)** 을 정규화 기준으로 사용해, 오른쪽으로 늘려도 기존 필기가 그대로 있게 합니다. `strokePath(stroke, scaleBase)`와 `toPoint`의 분모를 동일한 `scaleBase`로 통일합니다.
  - 기존 데이터: 예전에는 그릴 당시 컨테이너 폭 기준으로 저장되어 있어, 기준 폭이 다르면 비율은 유지된 채 전체 크기만 조금 달라 보일 수 있습니다. 파괴적 마이그레이션은 하지 않습니다.
- 기준 크기 산출(최초 1회, 클라이언트에서만): `long = Math.max(innerWidth, innerHeight)`, `short = Math.min(...)`; `baseWidth = long - 좌측 네비(80) - 좌우 여백(48)`, `baseHeight = short - 상단 오프셋(컨테이너 top 측정값) - 여백`, 각각 하한(640 / 320) 적용. 산출 후 `textFields.canvasBase = "w,h"` 로 저장하고 이후에는 저장값 사용.
- 배수 저장: `textFields.canvasGrid = "cols,rows"` (기본 `"1,1"`), 일간 라우트에서 `usePageText`로 읽고 씁니다. `strokes`와 간섭 없음.
- 캔버스 픽셀 크기 = `baseWidth*cols × baseHeight*rows`, DPR 상한 2 유지. 매우 큰 캔버스 방지를 위해 `cols`, `rows`는 각각 최대 5로 제한.
- 스크롤 래퍼: `overflow-auto` + `overscroll-contain`, 내부에 고정 픽셀 크기 필기판. 모눈은 기존 `bg-grid` 유틸을 내부 필기판에 적용.
- 컨트롤 줄: `ChevronsDown`/`ChevronsUp`/`ChevronsRight`/`ChevronsLeft` 아이콘 + 현재 배수 텍스트, 기존 디자인 토큰 사용.
