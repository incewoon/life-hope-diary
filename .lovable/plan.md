# 일간 플랜: 도구 라벨 제거 + 전체 영역 텍스트 입력으로 변경

필기 도구는 현재 동작 그대로 유지하고, 텍스트 입력 방식만 "상자 추가형"에서 "필기판 전체가 하나의 텍스트 면"으로 바꿉니다.

## 1. 도구영역 '자유 필기' 텍스트 삭제

툴바 왼쪽의 라벨을 없애고 도구 버튼부터 시작하도록 합니다(일간 플랜 필기판 기준).

## 2. 텍스트 입력: 전체 영역 편집

- 기존 텍스트 상자(추가/드래그/삭제) 개념을 완전히 제거합니다. `텍스트 추가` 버튼도 없앱니다.
- 텍스트 모드를 켜면 필기판 전체(가로·세로 늘린 크기 그대로)가 하나의 편집 영역이 되고, 커서는 **항상 왼쪽 상단부터** 시작합니다.
- 보드를 늘리면 편집 영역도 같은 크기로 자동 확장됩니다(별도 위치 조정 없음).
- 펜/지우개 모드에서는 편집 영역이 `pointer-events: none`이라 입력한 텍스트는 보이기만 하고 필기를 방해하지 않습니다.
- 텍스트는 필기 stroke와 별개 레이어이므로 필기 위/아래 겹쳐 사용 가능하며, 지우개는 기존처럼 필기에만 적용됩니다.

## 3. 입력 중 글자 크기·색상 변경

- 툴바의 글자 크기(작게/보통/크게)와 색상(펜 색상 팔레트 공유)을 텍스트 모드에서 함께 노출합니다.
- 동작 규칙:
  - 텍스트를 드래그 선택한 상태에서 고르면 → 선택 구간에 즉시 적용.
  - 선택 없이 고르면 → 그 시점 이후 입력하는 글자부터 적용(이전 글자는 그대로).
- 즉, 한 편집 영역 안에서 문단별·구간별로 크기와 색상이 섞여 저장됩니다.

## 4. 저장

- 서식이 포함된 내용을 페이지의 `canvasTexts` 필드에 문자열로 저장하고 500ms debounce 자동 저장(현행 `usePageText` 그대로).
- 기존에 텍스트 상자로 저장된 데이터가 있으면 로드 시 각 상자의 내용을 위에서부터 줄 단위로 이어붙여 새 형식으로 자동 변환합니다(내용 유실 없음).

## 기술 메모

- `src/components/CanvasTextLayer.tsx`: 상자 배열 렌더러 → 보드 전체를 덮는 단일 `contentEditable` 레이어로 재작성. 크기/색상 적용은 선택 영역에 `document.execCommand("foreColor"/"fontSize")` 계열(미선택 시 브라우저 기본 pending-format 동작)로 처리하고, 값은 `innerHTML`로 저장·복원. 저장 시 허용 태그(span/div/br/b/i/u)만 남기는 sanitize를 거칩니다.
- 구 형식 감지: 저장값이 `[`로 시작하는 JSON 배열이면 상자 배열로 파싱해 HTML로 1회 변환.
- `src/components/HandwritingCanvas.tsx`: `onAddText`/`텍스트 추가` 제거, `label` 렌더링 제거(또는 daily에서 `label` prop 미전달), 텍스트 모드일 때 툴바에 글자 크기 + 색상 팝오버 노출.
- `src/lib/pen-context.tsx`: 변경 없음(`textSize`, `color` 재사용).
- 배경 선택·늘리기·두 손가락 스크롤 등 나머지 동작은 그대로 유지합니다.
