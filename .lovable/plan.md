# 사용성 개선 3가지

## 1. 마지막 사용 위치 기억

앱을 다시 열면 마지막으로 보던 페이지가 바로 열리도록 합니다.

- 라우트가 바뀔 때마다 현재 경로를 기기 저장소(meta)에 기록합니다. 표지(`/`)는 기록하지 않습니다.
- 앱 시작 시 표지(`/`)로 들어오면 저장된 경로로 자동 이동합니다.
- 사용자가 표지를 보고 싶을 때를 위해 목차 등에서 표지로 돌아가는 링크는 유지하고, 표지에서 연도 버튼이나 "수첩 열기"를 직접 누른 경우에는 자동 이동을 다시 걸지 않습니다(같은 세션 내 1회만 복원).

## 2. 백업 알림을 배너 대신 토스트로

- 모든 페이지 상단의 백업 권장 배너와 버튼 영역을 제거합니다.
- 표지(첫 화면) 하단의 "모든 데이터는 이 기기 안에만 저장…" 로컬 저장/백업 안내 문구도 제거합니다.
- 대신 앱을 처음 설치·실행했을 때 딱 한 번만 "데이터는 기기에만 저장되니 주기적으로 백업하세요" 토스트를 표시합니다(표시 여부를 저장해 이후에는 다시 뜨지 않음).
- 그 이후에는 마지막 백업 후 30일이 지난 경우에만 백업 권장 토스트를 표시하고, 토스트의 "백업하기" 버튼으로 설정 페이지로 이동합니다. 마지막 안내 시점을 저장해 30일 간격으로만 표시합니다.

## 3. 고정 안내 페이지의 필기 기능 제거

다음 페이지는 읽기 전용 콘텐츠로만 표시합니다(필기 오버레이·펜 도구 제거).

- 링크·앱 안내
- 지역본부(Family) — 단, 이미 있는 "My Office" 입력란은 그대로 유지
- 중장기 경영전략, 8대 경영목표, 부패방지 및 규범준수 방침

필기가 필요한 월간/일간/회의록/노트/연락처 페이지는 변경하지 않습니다.

## 기술 메모

- `src/lib/db.ts`의 `META_KEYS`에 `lastRoute`, `lastBackupNoticeAt` 추가.
- 경로 기록/복원은 `__root.tsx`에 작은 훅으로 추가(`useRouterState`로 pathname 구독, 클라이언트에서만 동작). 표지에서 `useEffect` 1회 `navigate({ to: saved, replace: true })`.
- `src/components/BackupReminder.tsx` 제거하고 `PageShell`에서 사용 제거. 대신 `sonner` 토스트를 띄우는 `useBackupNotice()` 훅을 `__root.tsx`에서 1회 호출. `backupIsStale` 기준은 30일로 조정(백업 기록 없으면 첫 실행 시 1회 안내).
- `StaticPage.tsx`는 `HandwritingCanvas` 없이 콘텐츠만 렌더하도록 단순화(props 시그니처 유지). `family.tsx`에서 `HandwritingCanvas` 제거.
- 기존에 저장된 `static-*` 필기 데이터는 삭제하지 않고 그대로 둡니다(표시만 안 함).
- `META_KEYS`에 `onboardingNoticeShown`도 추가해 최초 1회 안내 여부를 기록합니다.
