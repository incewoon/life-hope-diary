# 일간 플랜 필기판: 텍스트 입력 · 배경 선택 · 도구 정리

기존 화이트 + LH 블루 톤, 한국어 UI, 오프라인(IndexedDB) 원칙 유지. DB 스키마 변경 없음(모두 해당 페이지의 `textFields`에 저장).

## 1. 키보드 텍스트 입력 (텍스트 상자, 삼성노트 스타일)

필기판 위에 텍스트 상자를 추가합니다. 생성 위치는 항상 왼쪽 상단입니다.

- 도구에 "텍스트" 모드 추가. 텍스트 모드로 전환하거나 툴바의 "텍스트 추가"를 누르면 새 상자가 **필기판 왼쪽 상단 여백**(정규화 좌표 x ≈ 0.03, y ≈ 0.03)에 생성됩니다.
- 빈 보드를 탭해도 그 위치에 상자를 만들지 않습니다(자유 탭 배치 없음). 이미 상자가 있으면 같은 자리에 겹치지 않도록 기존 상자들 아래쪽 가장 가까운 빈 여백으로 내려서 배치합니다.
- 생성 직후 자동 포커스되어 바로 타이핑할 수 있습니다.
- 각 상자: 내용 편집(자동 높이 textarea), 드래그로 위치 이동, 글자 크기(작게/보통/크게), 색상(펜 색상 팔레트 공유), 삭제 버튼.
- 좌표는 필기 stroke와 동일하게 `baseWidth` 기준 정규화 값으로 저장합니다.
- 저장: `textFields.canvasTexts`에 JSON 문자열, 500ms debounce (기존 `usePageText` 사용).

```ts
type TextBox = {
  id: string;
  x: number;   // baseWidth 기준 정규화 (0.03 근처에서 시작)
  y: number;   // baseWidth 기준 정규화
  text: string;
  size: "sm" | "md" | "lg";
  color: string;
};
// textFields.canvasTexts = JSON.stringify(TextBox[])
// 파싱 실패 또는 배열이 아니면 빈 배열로 fallback
```

## 2. 보드 확장과 텍스트 · 포인터 처리

- 텍스트 레이어는 필기 캔버스와 **같은 고정 보드 컨테이너**(width = `baseWidth*cols`, height = `baseHeight*rows`) 안에 absolute로 렌더링되어 스크롤 컨테이너를 함께 사용합니다. 보드가 화면보다 커지면 가로·세로 스크롤로 텍스트도 같이 이동합니다.
- cols/rows가 늘어나도 기존 상자의 위치·글자 크기는 스케일되거나 이동하지 않습니다(빈 공간만 오른쪽·아래로 추가).
- 펜/지우개 모드에서는 텍스트 레이어가 `pointer-events: none`이라 필기를 방해하지 않고, 텍스트 모드에서만 클릭·편집·드래그가 가능합니다.

## 3. 필기영역 배경 선택

기본값은 "없음"(흰 배경), 선택지는 없음 / 격자 / 도트 / 가로줄.

- 배경 유틸리티(`bg-grid`, `bg-dot`, `bg-line`)를 `src/styles.css`에 디자인 토큰 색상만으로 정의합니다(하드코딩 색 금지).
- 선택값은 `textFields.canvasBg`에 저장되어 페이지별로 유지됩니다. daily 페이지에 하드코딩된 `grid` prop은 제거하고 `canvasBg` 값으로 배경 클래스를 결정합니다.
- 배경은 확장된 전체 보드 크기에 타일링되며 필기·텍스트 레이어 아래에 놓입니다.

## 4. 도구 영역 재구성

버튼이 늘어난 만큼 툴바를 그룹 + 팝오버 방식으로 정리합니다.

```text
[ 자유 필기 ]  [펜|지우개|텍스트]  [● 펜 설정 ▾ / 글자크기]  [▦ 배경 ▾]  [↺ ↻ 🗑]   저장됨
```

- 왼쪽: 모드 토글 그룹(펜 / 지우개 / 텍스트) — 한 번에 하나만 선택되는 세그먼트 형태.
- 펜 설정: 현재 색·굵기를 미리보기로 보여주는 버튼, 누르면 팝오버 안에서 색상 3종 + 굵기 3종 선택.
- 텍스트 모드일 때는 펜 설정 자리에 글자 크기(작게/보통/크게) 선택과 "텍스트 추가" 버튼이 나타납니다.
- 배경: 팝오버 안에서 없음/격자/도트/가로줄 선택(선택된 항목 체크 표시).
- 오른쪽: 실행취소 / 다시실행 / 전체지우기 + 저장 상태 표시(현행 유지).

- 좁은 화면에서는 툴바가 가로 스크롤되지 않고 자연스럽게 줄바꿈되도록 유지합니다.

## 기술 메모

- 변경 파일: `src/components/HandwritingCanvas.tsx`(툴바·텍스트 레이어·배경 클래스), `src/lib/pen-context.tsx`(`tool`에 `"text"` 추가, 글자 크기 상태), `src/routes/daily.$year.$month.$day.tsx`(`canvasTexts`·`canvasBg` 필드 연결), `src/styles.css`(배경 유틸리티).
- 팝오버는 이미 설치된 shadcn `popover` / `toggle-group` 컴포넌트를 사용합니다(없으면 추가).
- 텍스트 상자·배경 기능은 `fixed` 모드(일간 플랜 필기판)에 적용하며, overlay 모드 페이지는 현행 유지합니다.
- 기존 데이터는 필드가 없으면 각각 빈 배열 / 배경 없음으로 동작하므로 유실 없습니다.
