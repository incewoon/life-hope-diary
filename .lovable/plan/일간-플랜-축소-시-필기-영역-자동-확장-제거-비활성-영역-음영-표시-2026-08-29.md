# 일간 플랜 — 축소 시 필기 영역 자동 확장 제거 + 비활성 영역 음영 표시

## 원인 (확인됨)

`src/components/HandwritingCanvas.tsx`의 `boardHeight` 계산(236-238행)이
`Math.max(baseBoardHeight * zoom, viewportHeight - 26)`으로 되어 있어,
확대/축소로 보드 높이가 스크롤 영역보다 작아지면 자동으로 세로가 늘어납니다.
가로(`boardWidth`)는 이 로직이 없어 고정이라 세로만 늘어나는 현상이 발생합니다.

## 변경 내용

### 1. 필기 영역 크기는 확장 버튼(배수)만으로 결정

- 보드 크기를 `baseWidth*cols*zoom × baseHeight*rows*zoom`으로 고정합니다.
- 축소(줌 아웃)해도 보드는 배율에 맞춰 작아질 뿐, 세로가 자동으로 늘어나지 않습니다.
- 스크롤 영역(뷰포트) 높이는 기존처럼 화면 하단까지 꽉 채운 높이를 유지합니다.
- 텍스트 입력 영역도 동일하게 보드 크기에만 맞춥니다(보드 밖으로 확장되지 않음).

### 2. 비활성 영역 음영 표시

- 보드가 스크롤 영역보다 작을 때(축소 또는 확장 전) 남는 오른쪽·아래 영역을
  배경보다 약간 어두운 색(디자인 토큰 `muted`/`secondary` 계열)으로 채웁니다.
- 보드 경계가 한눈에 보이도록 활성 보드는 기존 배경 + 얇은 테두리(`border`) 유지,
  비활성 영역은 균일한 음영만 표시(격자/도트 등 배경 무늬는 활성 영역에만 그림).
- 확장 버튼을 눌러 배수가 늘어나면 음영이 줄어들고 활성 필기 영역이 그 자리를 차지합니다.

### 3. 기존 동작 유지

- 두 손가락 이동, 두꺼운 스크롤바, 확대/축소 버튼, 배경 선택, 형광펜 등 나머지 동작은 그대로.

## 기술 메모

- `src/components/HandwritingCanvas.tsx`
  - `boardHeight`에서 `Math.max(..., viewportHeight)` 자동 확장 제거 → `baseBoardHeight * zoom` 고정.
  - `resize()`의 높이 계산도 동일 기준으로 정리.
  - 스크롤 컨테이너(fixed 모드)에 음영 배경 클래스 적용(예: `bg-muted`), 보드 div는 `bg-card` + `border` 유지.
  - 스크롤 콘텐츠 크기 계산: `max(boardWidth, containerWidth)` 식으로 보드가 작으면 뷰포트 너비만큼만 차지하게 하여 음영이 보드 주변에 보이도록 조정.
- `src/styles.css`: 별도 토큰 추가 없이 기존 `muted` 토큰 사용.
