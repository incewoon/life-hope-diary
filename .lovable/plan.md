# 목차·일간 플랜 개선

## 1. 목차 페이지의 연도 선택 영역 제거

- 목차 상단의 "연도" 라벨 + 연도 버튼 묶음을 삭제합니다.
- 연도 변경은 표지(메인 화면)에서만 가능합니다. 목차는 현재 선택된 연도를 부제(`2026년 업무수첩`)로 표시만 하고, 연간 달력·월간·일간 바로가기는 지금처럼 선택된 연도를 그대로 사용합니다.

## 2. 일간 플랜: 텍스트 3칸 제거 → 일정 관리로 교체

- "오늘의 목표 / 핵심 일정 / 체크 사항" 입력 영역과 해당 데이터 필드를 완전히 제거합니다(해당 키는 더 이상 읽지도 쓰지도 않음).
- 그 자리에 일정 영역을 넣습니다.
  - 일정이 하나도 없으면 "새 일정" 버튼만 보입니다.
  - 일정을 추가하면 "새 일정" 버튼 오른쪽에 일정들이 버튼(칩) 형태로 나란히 붙습니다. 칩에는 시간과 일정 이름이 보입니다.
  - 칩을 누르면 같은 팝업이 열려 수정할 수 있고, 팝업 안에서 삭제도 가능합니다.
- 입력 팝업(모달) 구성:
  - 날짜: 달력에서 클릭 선택(기본값은 현재 보고 있는 날짜)
  - 시간: 시계 형태의 직관적 선택(시/분 다이얼)
  - 일정 이름: 텍스트 입력
  - 저장 / 취소 / (기존 일정일 때) 삭제
- 일정은 시간순으로 정렬해 표시합니다.
- 필기 캔버스 영역은 그대로 유지합니다.

## 기술 메모

- `src/routes/contents.tsx`: 연도 버튼 블록 삭제, `setYear`·`yearOptions` 임포트 정리(`year`는 유지).
- `src/routes/daily.$year.$month.$day.tsx`: 3개 textarea 제거. 일정 데이터는 기존 `usePageText`의 `textFields.schedule`에 `{ id, at: ISO, title }[]` JSON 문자열로 저장(월간 체크리스트와 동일한 방식). 필기 `strokes`와 간섭 없음.
- 새 컴포넌트 `src/components/DaySchedule.tsx`: 칩 목록 + 편집 다이얼로그. shadcn `Dialog`, `Calendar`(`pointer-events-auto` 포함), `Button`, `Input` 사용.
- 시계 선택기: 시(12개)·분(5분 단위) 다이얼을 원형 배치한 경량 컴포넌트로 구현하고, 접근성 보완용으로 `HH:MM` 직접 입력도 함께 둡니다.
- 기존에 저장된 `오늘의 목표` 등 텍스트 값은 마이그레이션 없이 그대로 두되 화면에서는 사용하지 않습니다.
